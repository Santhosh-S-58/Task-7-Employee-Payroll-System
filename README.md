Task 7 – Employee Payroll System (Java)

Description
This project demonstrates inheritance and runtime polymorphism
using an employee payroll system. Different employee types
calculate salaries differently using method overriding.

Concepts Used
- Inheritance
- Method overriding
- Runtime polymorphism
- super keyword
- Parent reference to child object

How to Run
javac EmployeePayroll.java  
java EmployeePayroll
